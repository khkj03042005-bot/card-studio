# T05 공통 사용량 상한 (작업 전 고정, AI A·AI B 동일 적용)

- 시간 상한: AI당 실제 작업 30분 이하
- 요청·호출 상한: AI당 요청(프롬프트 전송) 15회 이하

## 개선 기능
JSON 백업 복원 시 중복 템플릿 처리 (`mergeTemplates`).
- 같은 id + 같은 내용 → 건너뜀(skipped)
- 같은 id + 다른 내용 → 새 id 부여 후 둘 다 보존(renamed)
- 새 id → 추가(added)
- 합계 300개 초과 시 오류

## 고정 검사 10개 (작업 시작 후 삭제·조건 완화·기대값 변경 금지)
| ID | 입력 | 기대값 |
|---|---|---|
| C01 | 기존 [], 들어옴 [A] | added=1, merged 길이 1 |
| C02 | 기존 [A], 들어옴 [A 동일] | skipped=1, merged 길이 1 |
| C03 | 기존 [A], 들어옴 [같은 id, 내용 다름] | renamed=1, merged 길이 2, id 서로 다름 |
| C04 | 기존 [], 들어옴 [A, A 동일] (백업 파일 실제 사례) | added=1, skipped=1, 길이 1 |
| C05 | 기존 [], 들어옴 [] | 모두 0, 길이 0 |
| C06 | 기존 299개, 들어옴 새 1개 (경계: 합계 300) | 오류 없음, 길이 300 |
| C07 | 기존 300개, 들어옴 새 1개 (경계: 301) | 오류 '최대 300개' |
| C08 | 기존 300개, 들어옴 기존과 동일 1개 | 오류 없음, skipped=1, 길이 300 |
| C09 | 들어옴 id가 없는 항목 | 새 id가 부여되어 added=1, id 비어 있지 않음 |
| C10 | 호출 후 기존 배열 | 원본 배열 길이·내용 변경 없음 |
