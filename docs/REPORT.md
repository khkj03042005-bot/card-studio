# T05 AI 세션 간 인수인계 비교 보고서

개선 기능: JSON 백업 복원 시 중복 템플릿 처리 (`lib/merge.js` `mergeTemplates`)

## 비교표 (모델·서비스 이름 블라인드)

| 항목 | AI-1 | AI-2 |
|---|---|---|
| 작업 시간 | 10분 | 9분 |
| 요청·호출 수 | 5회 | 1회 |
| 오류 회차 수 | 1 | 0 |
| 검사 통과 수 (10개 중) | 9 | 10 |

- 공통 상한: 시간 30분, 요청 15회. 두 AI 모두 상한 이내.
- 오류 회차 수: 고정 검사 10개 중 하나 이상 FAIL이 난 실행 회차 수. AI-1은 종료 시점 실행이 9/10(C07 FAIL)이었다. AI-2는 AI-1이 남긴 인수인계문만 받고 이어서 완성했으며, 최종 실행은 10/10이다.
- AI-2의 수정안은 저장소 쓰기 권한이 없어 사람이 그대로 커밋했다(코드 내용 무변경).

## 작업 순서
1. 검사 10개와 공통 상한을 먼저 고정 (시작 소스 `c41c701`)
2. AI-1 시작 → 중복 id 처리 구현 → 인수인계 문서 작성 → AI-1 종료 (`09d0244`, 9/10)
3. AI-2 시작 → 인수인계문만 받아 상한 오류(C07)와 화면 연결 → AI-2 종료 (`7265dd2`, 10/10)

## 확인 방법
1. 어디에: 위 종료 소스 커밋, 브랜치 `t05-ai-a`
2. 3단계 이내: ① 저장소를 받고 `t05-ai-a`로 전환 ② `node tests/checks.js` 실행 ③ `index.html`을 열어 `card-studio-backup.json` 복원
3. 통과: `10/10 통과`, 화면에 `추가 1개 · 건너뜀 1개`
