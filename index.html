짤·카드 스튜디오

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 파일로 저장하세요.

1. 이미지와 크기

이미지를 올리지 않으면 단색 배경으로 시작합니다. 파일은 이 브라우저에서 처리됩니다.

이미지 바깥 여백 및 기본 배경에 사용됩니다.

공개 이미지 사용 시 출처와 이용 허가 근거를 기록하세요. 캔버스로 다시 저장해 원본 파일 메타데이터는 출력 이미지에 포함하지 않습니다.

2. 문구와 디자인

3. 템플릿 관리

템플릿은 현재 브라우저에 저장됩니다. JSON 백업 파일을 별도로 보관하세요.

4. 다운로드

1:1(1080×1080), 4:5(1080×1350), 9:16(1080×1920) PNG 3개를 차례로 다운로드합니다.

준비되었습니다. 문구를 수정하면 미리보기가 자동으로 갱신됩니다.

실시간 미리보기

미리보기 = 다운로드 렌더링
안내: 최종 저장 파일은 위 캔버스를 동일한 렌더링 함수로 출력합니다. 이미지 원본은 서버로 전송하지 않습니다.

빠른 확인 방법

  1. PNG와 JPEG 파일을 각각 업로드하고 미리보기를 확인합니다.
  2. 문구·색상·크기·위치를 변경해 미리보기가 즉시 바뀌는지 확인합니다.
  3. PNG와 JPEG를 내려받아 이미지 뷰어에서 열어 비교합니다.
  4. 템플릿 저장·불러오기·수정·삭제와 JSON 백업·복원을 확인합니다.

AI 사용 판단 예시

  1. AI는 기능 설계와 코드 초안 작성에 보조적으로 활용했습니다.
  2. 파일 업로드·렌더링·다운로드 및 템플릿 기능은 직접 실행해 검증해야 합니다.
  3. 검증하지 않은 결과를 완료했다고 표시하지 않고, 발견한 오류는 수정 후 재검사합니다.
